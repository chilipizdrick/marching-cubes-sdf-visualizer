# SDF Visualizer

### A simple tool to visualize signed distance fields (SDFs) in 3D.

It is by no means a complete tool, it is more of an excersise in learning computer graphics.

## Keybindings

| Key | Action |
| --- | --- |
| <kbd>W</kbd> | Move forward |
| <kbd>A</kbd> | Move left |
| <kbd>S</kbd> | Move backward |
| <kbd>D</kbd> | Move right |
| <kbd>Space</kbd> | Move up |
| <kbd>Control Left</kbd> | Move down |
| <kbd>Shift Left</kbd> | Sprint |
| <kbd>Esc</kbd> | Switch between camera/GUI mode |
